# POL-02 — Data Handling Policy

*Simulated training policy.*

## 1. Synthetic-only rule

All operational data in DOIP is synthetic, generated by the simulation engine or authored as exercise content. It is prohibited to load real operational data — real unit positions, real personnel records, real sensor feeds, or classified material of any kind — into any DOIP environment. There is no approved exception path; a system that never contains real data cannot leak it.

## 2. Personnel data

Simulated personnel (names, vitals, rosters) are generated fictions. Real user accounts hold only: username, role, and authentication credentials. User activity (decisions, acknowledgments, annotations) is logged for training review — participants must be informed that exercise performance is recorded and replayable.

## 3. Retention and replay

Event logs are append-only and retained for the training program's review period. Runs may be deleted only whole (run-level purge by an admin, itself an audited action) — selective event deletion is prohibited because it breaks replay integrity.

## 4. Exports

After-action reports and analytics exports inherit this policy: synthetic content, role names rather than personal blame framing (POL-03), and the standing disclaimer — *“Training & simulation platform. All data is synthetic. Not for operational military use.”*
